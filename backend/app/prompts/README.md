# Промпты

Тексты промптов для Claude в markdown, по одному файлу на шаг конвейера, с номером версии в имени: `analysis.v3.md`, `parse_input.v1.md`.

- Опубликованную версию не правим: изменение — новый файл со следующим номером.
- Какая версия активна, хранится в базе (`strategy_versions`), переключает администратор после проверки на eval-наборе ([LLM_LEARNING.md](../../../docs/LLM_LEARNING.md), раздел 3.4).
- Исходные правила стратегии лежат в старом боте: `legacy/telegram-bot/Tennis-Analytics/Стратегия-ставок.md`. На этапе 3 они переносятся сюда.
