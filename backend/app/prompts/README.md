# Промпты

Тексты промптов для Claude в markdown, по одному файлу на шаг конвейера, с номером версии в имени: `analysis.v1.md`, `parse_input.v1.md`.

- Опубликованную версию не правим: изменение — новый файл со следующим номером. Тест `tests/test_agent_prompts.py` сверяет sha256 опубликованных файлов.
- Какая версия анализа активна, хранится в базе (`strategy_versions.prompt_version`, например `analysis.v1`), переключает администратор после проверки на eval-наборе ([LLM_LEARNING.md](../../../docs/LLM_LEARNING.md), раздел 3.4).
- Исходные правила стратегии лежат в старом боте: `legacy/telegram-bot/Tennis-Analytics/Стратегия-ставок.md`. В `analysis.v1.md` из них осталось только то, что влияет на оценку вероятности; правила экспресса и суммы считает код (`app/ml/strategy.py`).
- В промптах и схемах ответа нет слов reasoning, thinking, trace и просьб «рассуждать по шагам»: на них модель отвечает отказом.
- Дата и все переменное — в сообщении пользователя (`*_request`), а не в system: так префикс кэшируется.
