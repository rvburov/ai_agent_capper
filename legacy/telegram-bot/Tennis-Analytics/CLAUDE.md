# CLAUDE.md — Tennis-Analytics

## Как работает система

Вы вводите одно сообщение с матчами и кэфами.
Claude Code делает все остальное сам: заполняет базу, обновляет данные, анализирует, записывает историю.

## Что вводите вы

```
Текущий банк: ___₽
Букмекер: [название]

События:
[Игрок1] vs [Игрок2], [турнир], [покрытие]
Кэфы [БК]: П1 = X.XX, П2 = X.XX
Фора по сетам: П1(+1.5) = X.XX, П1(-1.5) = X.XX, П2(-1.5) = X.XX, П2(+1.5) = X.XX
```

После матча:
```
РЕЗУЛЬТАТ СТАВКИ: победа / поражение
```

## Что делает Claude Code автоматически

1. Читает `Ставки/История-ставок.json` → берет банк, серию, адаптации
2. Для каждого игрока → проверяет базу → заполняет если нет → обновляет если устарело
3. Проводит анализ по `Стратегия-ставок.md` — кэфы берет прямо из вашего сообщения
4. Выдает один экспресс с суммой
5. Записывает полную ставку в `История-ставок.json` (события + кэфы + анализ + экспресс)
6. Каждые 10 ставок — аудит и корректировка стратегии

Папки `Матчи/` нет — все данные о событиях хранятся в `История-ставок.json`.

## Типы данных

| Файл | Тип | Кто заполняет | Когда |
|------|-----|---------------|-------|
| 01–04 | Статика | Claude Code | Один раз при новом игроке |
| 05–06 | Динамика | Claude Code | Перед каждым матчем авто |
| История-ставок.json | История | Claude Code | После каждого анализа и результата |

## Источники (Claude Code ищет сам)

- atptour.com — рейтинг, личные данные
- flashscore.com — форма, результаты, статистика матчей
- tennisexplorer.com — H2H, статистика по покрытиям
- sofascore.com — детальная статистика

---

## Правила

- `_Шаблоны/` — не редактировать, только копировать
- Кэфы берутся из вашего сообщения — не из интернета
- Во время анализа (Шаги 0–6) интернет не использовать
- Один запуск = один экспресс, максимум 3 события
- Банк обновляется только после результата ставки
