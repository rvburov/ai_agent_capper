# Старый Telegram-бот (не развивается)

Первая версия AI Capper: Telegram-бот, который анализировал матчи через Claude и хранил базу в JSON и markdown. По решению Р2 ([PLAN.md](../../docs/PLAN.md), раздел 0) бот не развивается и не разворачивается: его заменяет веб-приложение.

## Зачем он лежит в репозитории

| Что | Где | Куда переходит |
|---|---|---|
| Стратегия ставок и сценарий анализа | `Tennis-Analytics/Стратегия-ставок.md`, `Инструкция-*.md`, `Tennis-Analytics/CLAUDE.md` | Промпты `backend/app/prompts/` (этап 3) |
| Шаблоны профиля игрока | `Tennis-Analytics/_Шаблоны/*.json` | Таблицы игроков в PostgreSQL (этап 1–2) |
| История ставок | `Tennis-Analytics/Ставки/История-ставок.json` (в git не хранится) | Импорт в базу (этап 1) |
| Код бота | `bot.py` | Разбор недостатков — [PLAN.md](../../docs/PLAN.md), раздел 2 |

`deploy.yml` — старый сценарий автодеплоя GitHub Actions. Он выключен (лежит вне `.github/workflows/`) и был настроен на ветку `main`, которой в репозитории нет.

## Если все же нужно запустить

Бот в текущем виде не запускается и небезопасен (PLAN.md, раздел 2, пункты 1–3). Если он нужен до запуска веб-версии, сначала внесите исправления из раздела «Если бот нужен до запуска веб-версии», затем:

```bash
cd legacy/telegram-bot
cp .env.example .env               # вставьте TELEGRAM_TOKEN и ANTHROPIC_API_KEY
mkdir -p Tennis-Analytics/Игроки Tennis-Analytics/Ставки && touch bot.log
docker compose up --build
```

Команды бота: свободный текст с матчами и кэфами — анализ и экспресс; `/статистика`, `/игроки`, `/результат`.
