# Инструкция 2 — Обновление перед матчем

## Когда использовать
Перед каждым матчем. За 1–2 дня до игры.
Обновляются только динамические файлы 05 и 06.
Статику (01–04) НЕ трогать.

---

## Формат запроса

```
КОМАНДА: обновить игрока
Игрок: [Имя Фамилия]
Папка: Игроки/[Имя-Фамилия]/
Дата матча: [ДД.ММ.ГГГГ]
```

**Пример:**
```
КОМАНДА: обновить игрока
Игрок: Карлос Алькарас
Папка: Игроки/Карлос-Алькарас/
Дата матча: 15.05.2026
```

**Обновление двух игроков сразу:**
```
КОМАНДА: обновить игроков
Матч: Джокович vs Алькарас
Дата матча: 15.05.2026
Папки: Игроки/Новак-Джокович/ и Игроки/Карлос-Алькарас/
```

---

## Что делает Claude Code

### Шаг 1 — Читает текущие файлы
Читает `05-текущее-состояние.json` и `06-матчи.json` чтобы понять что уже есть.
Определяет дату последнего обновления из `meta.дата_обновления`.

### Шаг 2 — Ищет только новое
Ищет только данные которых ещё нет в файле. Не перезаписывает то, что уже заполнено.

**Что ищет для файла 05:**
- Текущий рейтинг ATP и позиция → atptour.com
- Травмы и физическое состояние → flashscore.com, новости, соцсети игрока
- Усталость: количество матчей за последние 14 дней → flashscore.com
- Дней отдыха перед матчем → flashscore.com (расписание турнира)
- Мотивация: категория турнира, важность для рейтинга → atptour.com

**Что ищет для файла 06:**
- Результаты матчей начиная с даты последнего обновления
- Полную статистику каждого матча (подача, возврат, очки, геймы)
- Источник: flashscore.com → страница игрока → результаты

### Шаг 3 — Записывает изменения
**Файл 05:** перезаписывает полностью (актуальное состояние)
**Файл 06:** добавляет новые матчи в начало массива. Старые не трогает.
Обновляет `meta.дата_обновления` на текущую дату.

### Шаг 4 — Отчёт

```
✅ Обновлён: Игроки/Карлос-Алькарас/
   05-текущее-состояние.json — рейтинг 2, состояние: здоров, усталость: умеренная
   06-матчи.json — добавлено 3 новых матча (итого в базе: 10)
⚠️ Не найдено: информация о травмах (поле оставлено пустым)
```

---

## Ограничения (экономия токенов)

- Максимум 6 поисковых запросов на игрока
- НЕ читать файлы 01–04 — они не нужны для обновления
- НЕ искать данные старше 30 дней — они уже в базе
- Если матч в 06 уже есть (проверка по дате + сопернику) — не дублировать
- Для файла 06 искать максимум последние 10 матчей

---

## Что НЕ нужно обновлять

- Файлы 01, 02, 03, 04 — статика, не трогать
- Матчи которые уже есть в 06-матчи.json
- Исторические данные старше последнего обновления
