# Инструкция-3-анализ.md — Анализ и прогноз

## Когда использовать
Запускается автоматически как часть Инструкции-Авто.md (Шаг C).
Кэфы берутся из вашего сообщения — отдельный файл матча не создаётся.

---

## Предварительные условия

Перед анализом должны быть выполнены Шаги A и B (Инструкция-Авто.md):
- [ ] Оба игрока есть в папке `Игроки/`
- [ ] Файлы 05 обоих игроков обновлены не позднее 2 дней
- [ ] В файле 06 каждого игрока минимум 3 матча
- [ ] Кэфы присутствуют в вашем сообщении

---

## Что делает Claude Code

### Шаг 0 — Проверка данных

Читает файлы обоих игроков.
Проверяет полноту по чеклисту из `Стратегия-ставок.md`.

**Критичные данные отсутствуют → стоп:**
```
⛔ Анализ невозможен:
- Игрок1: 05 устарел (обновлён: ДД.ММ.ГГГГ)
- Игрок2: 06 — только 1 матч, нужно 3+
Запустите обновление (Шаг B) и повторите.
```

**Некритичные данные отсутствуют → предупреждение и продолжение:**
```
⚠️ Неполные данные (уверенность снижена):
- Игрок1: 04 — поле "реакция_на_давление_трибун" пустое
```

### Шаги 1–5 — Анализ по стратегии

Выполняет Шаги 1–5 из `Стратегия-ставок.md`:
- Читает и сравнивает данные игроков
- Кэфы берёт из вашего сообщения (не из файлов, не из интернета)
- Рассчитывает вероятности и валуй
- Формирует экспресс и считает сумму

### Шаг E — Записывает в историю

Результат анализа пишется напрямую в `Ставки/История-ставок.json`.
Файл матча не создаётся — все данные события уже внутри записи истории.

---

## Ограничения

- Во время анализа НЕ искать в интернете — только читать файлы базы
- Кэфы брать только из вашего сообщения
- Один запуск = один экспресс = максимум 3 события
- Без актуального файла 05 анализ не проводить

---

## Частые ошибки

| Ошибка | Что делать |
|--------|------------|
| Файл 05 устарел | Шаг B выполнится авто при следующем запуске |
| Менее 3 матчей в 06 | Шаг B доищет авто |
| Кэфы не указаны в сообщении | Добавьте кэфы и повторите |
| Банк не указан | Claude Code возьмёт из `История-ставок.json` |
