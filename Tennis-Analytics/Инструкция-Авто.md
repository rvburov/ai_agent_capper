# Инструкция-Авто.md — Полная автоматизация

## Что делает Claude Code при получении входных данных

Получив сообщение с матчами — Claude Code выполняет всё сам:
1. Читает историю из `Ставки/История-ставок.json`
2. Для каждого игрока: проверяет базу, заполняет если нет, обновляет если устарело
3. Проводит анализ, кэфы берёт прямо из вашего сообщения
4. Записывает ставку в `История-ставок.json`

Папки `Матчи/` нет — кэфы и данные событий хранятся внутри каждой записи в `История-ставок.json`.

---

## Формат вашего сообщения

```
Текущий банк: ___₽
Букмекер: [название]

События:
[Игрок1] vs [Игрок2], [турнир], [покрытие]
Кэфы [БК]: П1 = X.XX, П2 = X.XX
Фора по сетам: П1(+1.5) = X.XX, П1(-1.5) = X.XX, П2(-1.5) = X.XX, П2(+1.5) = X.XX

[следующий матч...]
```

## Алгоритм автозапуска (шаги A → E)

### Шаг A — Читает историю ставок

Открывает `Ставки/История-ставок.json`.
Извлекает:
- Текущий банк (из файла если есть, иначе из вашего сообщения)
- Серию побед/поражений
- Винрейт за последние 10 ставок
- Все параметры адаптации из `Стратегия-ставок.md` Шаг 5

### Шаг B — Для каждого игрока

**Б1. Папки нет → создаёт базу (Инструкция-1):**
- Ищет данные в интернете (max 4 запроса)
- Создаёт папку `Игроки/Имя-Фамилия/`
- Записывает файлы 01–04

**Б2. Папка есть, файл 05 устарел (>2 дней) → обновляет (Инструкция-2):**
- Обновляет 05: рейтинг, состояние, усталость, мотивация
- Добавляет новые матчи в 06

**Б3. Файл 06 содержит менее 3 матчей → доищет до минимума.**

### Шаг C — Анализ

Читает файлы игроков. Кэфы берёт прямо из вашего сообщения.
Выполняет Шаги 0–6 из `Стратегия-ставок.md`.
Файлы матчей не создаёт — данные событий идут напрямую в анализ и в историю.

### Шаг D — Формирует экспресс

По правилам из `Стратегия-ставок.md` Шаги 4–5.
Один экспресс, максимум 3 события.

### Шаг E — Записывает в историю

Добавляет новый объект в `Ставки/История-ставок.json`:
- Все события с кэфами из вашего сообщения
- Выбранный рынок и кэф для каждого события
- Итоговый экспресс
- Анализ и обоснование
- Поле `результат` — пустое, заполняется после матча

## Как внести результат

```
РЕЗУЛЬТАТ СТАВКИ: победа / поражение
```

Claude Code:
1. Находит последнюю открытую запись в `История-ставок.json`
2. Заполняет `результат.статус`
3. Считает `банк_после` и `прибыль_убыток`
4. Обновляет `статистика` в `meta` блоке
5. Если прошло 10 ставок — запускает аудит автоматически

---

## Как Claude Code учится на истории

При каждом анализе читает `История-ставок.json` и применяет адаптации:

**По серии (Стратегия-ставок.md Шаг 5):**
- 3 поражения подряд → сумма −40%
- Банк −20% → консервативный режим

**Аудит каждые 10 ставок — корректирует стратегию:**
- Какие рынки прибыльны (исход vs фора)
- Какой диапазон кэфов работает
- На каком покрытии винрейт выше
- Выводы применяются к следующим ставкам

```
--- АУДИТ (ставки №1–10) ---
Винрейт: 60% (6 из 10)
Прибыль: +450₽ (+4.5%)

Работает: П2(+1.5) на грунте — 4 из 5
Не работает: П(-1.5) — 1 из 4
Изменение: снизить приоритет П(-1.5) на 5 ставок
```
