# Инструкция 1 — Заполнение базы (новый игрок)

## Когда использовать
Только когда игрок появляется в базе впервые.
Заполняются файлы 01–04 (статические данные). Один раз. Больше не трогать.

---

## Формат запроса

```
КОМАНДА: новый игрок
Игрок: [Имя Фамилия]
Папка: Игроки/[Имя-Фамилия]/
```

**Пример:**
```
КОМАНДА: новый игрок
Игрок: Карлос Алькарас
Папка: Игроки/Карлос-Алькарас/
```

---

## Что делает Claude Code

### Шаг 1 — Поиск данных
Ищет информацию по источникам в следующем порядке:
1. atptour.com — рейтинг, личные данные, статистика по покрытиям
2. tennisexplorer.com — хват, стиль, H2H
3. flashscore.com — подтверждение данных
4. sofascore.com — дополнительные детали

### Шаг 2 — Запись файлов
Создает папку `Игроки/[Имя-Фамилия]/` и записывает 4 файла:
- `01-личные-данные.json`
- `02-игровой-профиль.json`
- `03-физика-и-техника.json`
- `04-психология.json`

Копирует структуру из `_Шаблоны/`, заполняет найденными данными.
Поля, которые не удалось найти — оставляет `null` или `""`.

### Шаг 3 — Отчет
Выводит список заполненных и незаполненных полей.

---

## Ограничения (экономия токенов)

- НЕ заполнять файлы 05 и 06 — они заполняются отдельно (Инструкция 2)
- НЕ искать матчи и текущий рейтинг — только стабильные данные
- Максимум 4 поисковых запроса на игрока
- Если данные не найдены за 4 запроса — оставить null, не продолжать поиск

---

## Поля которые НЕ нужно искать (оставить null)

- Текущий рейтинг ATP → файл 05
- Последние матчи → файл 06
- Травмы → файл 05
- Усталость → файл 05

---

## Пример отчета после заполнения

```
✅ Создана папка: Игроки/Карлос-Алькарас/
✅ 01-личные-данные.json — заполнен полностью
✅ 02-игровой-профиль.json — заполнен полностью
⚠️ 03-физика-и-техника.json — оценки выставлены на основе анализа, проверьте
⚠️ 04-психология.json — тип характера: не найдено прямых данных, выставлено на основе наблюдений

Незаполненные поля: 03 → гибкость (null), 04 → реакция на давление трибун (null)
Следующий шаг: Инструкция 2 перед матчем
```
