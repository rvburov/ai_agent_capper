# Как получить свой ключ Claude API и подключить его к AI Capper

Эта инструкция для участников, которые хотят работать на своем ключе, а не на ключе администратора ([PLAN.md](PLAN.md), решение Р7). В приложении этот текст показывается во вкладке «Личный кабинет → Ключ Claude».

Сверено с документацией Anthropic 7 октября 2026 ([Get your Claude API key](https://platform.claude.com/docs/en/get-api-key)). Интерфейс консоли со временем меняется. Если названия кнопок разошлись с инструкцией, ориентируйтесь на смысл шагов.

## Сначала проверьте две вещи

1. **Подписка Claude и API — разные вещи.** Подписка Claude Pro или Max на claude.ai дает доступ к чату, но не дает ключа API. Для ключа нужен отдельный аккаунт в Claude Console, и токены там оплачиваются отдельно, по факту использования.
2. **Страна.** Claude API доступен только в [поддерживаемых странах](https://www.anthropic.com/supported-countries). Если вы находитесь в стране, которой нет в списке, использовать API нельзя по условиям Anthropic. Не обходите это ограничение через VPN.

## Шаги

1. Откройте [platform.claude.com](https://platform.claude.com/) и создайте аккаунт или войдите в существующий.
2. Пополните баланс в разделе **Billing** (Settings → Billing): API оплачивается за использованные токены.
3. Поставьте месячный **лимит трат** в той же консоли (Billing или Limits). Это ваша страховка: дороже лимита запросы не пройдут.
4. Откройте **Settings → API keys** ([прямая ссылка](https://platform.claude.com/settings/keys)) и нажмите **Create key**.
5. Задайте имя, например `AI Capper`, и срок действия. Если консоль предлагает тип ключа, выберите личный ключ (personal key).
6. **Скопируйте ключ сразу.** Он начинается с `sk-ant-` и показывается только один раз. Если не успели, удалите его и создайте новый.
7. В AI Capper откройте **«Личный кабинет → Ключ Claude»**, выберите режим **«Свой ключ»**, вставьте ключ и нажмите **«Проверить и сохранить»**.

Приложение отправит легкие проверочные запросы (список моделей и доступ к трем моделям, которые использует анализ: Haiku 5.5, Sonnet 5.5, Opus 5.5; токены они не тратят) и, если все в порядке, покажет «Ваш ключ sk-ant-…XXXX · проверен». Сохраняется только ключ, который прошел проверку. Весь ключ больше нигде не показывается: он хранится на сервере в зашифрованном виде. Нулевой баланс и лимит трат такая проверка не видит: они выяснятся на первом анализе.

## Как это работает дальше

- Все ваши анализы, разборы ставок и обновления ваших данных оплачиваются с вашего баланса в консоли Anthropic. Лимиты администратора на вас не действуют, кроме потолка стоимости одного анализа: его вы ставите сами в «Личном кабинете → Ключ Claude» (от $0,10 до $20, по умолчанию $1).
- **Новости внутри анализа оплачивает ключ, на котором идет анализ.** Если новости игрока старше 12 часов, перед анализом их ищет Claude Sonnet 5.5 с веб-поиском (≈ $0,05 на матч). На своем ключе это идет с вашего счета и входит в стоимость анализа и в ваш потолок. Найденные новости попадают в общий кэш: следующие 12 часов их берут из базы бесплатно все участники.
- Сколько вы потратили, видно в приложении («ИИ и расходы») и в консоли Anthropic. Цифры могут немного расходиться: консоль обновляется с задержкой.
- Общие фоновые задачи (ночное обновление базы игроков и новостей для всех) оплачивает администратор.
- Вернуться на ключ администратора можно в том же разделе: нажмите «Попросить администратора вернуть ключ», решение придет уведомлением. Когда администратор разрешит, свой ключ удалится с сервера: отзовите его в консоли Anthropic, если он больше не нужен. Чтобы снова перейти на свой ключ, его нужно будет ввести заново.

## Безопасность

- Никому не пересылайте ключ: ни в чате, ни по почте, ни администратору. Ключ вводится только в поле приложения.
- Если ключ мог утечь, удалите его в консоли (Settings → API keys) и создайте новый, затем замените его в приложении.
- Если закончились деньги на балансе или ключ отозван, приложение остановит анализ с понятной ошибкой и пришлет уведомление.

## Частые вопросы

**Сколько это стоит?** Ориентир — около $0,30 за анализ двух матчей. При 1–2 анализах в день получится $10–20 в месяц. Точный расчет — в [TOKEN_ECONOMY.md](TOKEN_ECONOMY.md).

**Можно ли использовать ключ от подписки Claude Pro или Max?** Нет. У подписки нет ключа API, нужен аккаунт в Claude Console.

**Можно ли одним ключом пользоваться вдвоем?** Не стоит: за все, что происходит под ключом, отвечает владелец аккаунта, а расходы смешаются. Каждому участнику — свой ключ или ключ администратора с лимитом.
