# Lab

Учебный трек по обучению LLM на данных проекта ([LLM_LEARNING.md](../docs/LLM_LEARNING.md), раздел 5). На работу приложения не влияет.

| Папка | Что внутри |
|---|---|
| `notebooks/` | Ноутбуки Jupyter: разбор данных, базовая модель, метрики |
| `datasets/` | Скрипты экспорта обезличенных прогнозов и исходов в JSONL (сами данные в git не кладем) |
| `configs/` | Настройки SFT + LoRA и GRPO для открытой модели 0,5–3B |

Обучение идет на открытой модели. Ответы Claude для обучения конкурирующих моделей использовать нельзя (условия Anthropic, см. [PLAN.md](../docs/PLAN.md), раздел 11, вопрос 14).
